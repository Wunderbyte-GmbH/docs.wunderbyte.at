# Booking guides

`moodle-mod_booking` is a feature-rich Moodle activity for managing bookable options such as workshops, appointments, course dates, recurring sessions, and bundled training offers.

## Key concepts

### Booking activity vs. booking option

- A **Booking activity** is the Moodle activity added to a course.
- A **booking option** is one concrete item users can book inside that activity.

One Booking activity can contain many options, each with its own title, dates, capacity, availability restrictions, notifications, and automation.

### Rules vs. actions after booking

The source docs distinguish two automation models:

- **Booking rules** run on a schedule or on Moodle events and usually send or trigger follow-up actions.
- **Actions after booking** run immediately when a booking answer is created, confirmed, or deleted.

### Free and PRO scope

Several advanced features documented in the source branch are explicitly marked as **PRO**, including many booking conditions, sub-bookings, campaigns, and actions after booking.
