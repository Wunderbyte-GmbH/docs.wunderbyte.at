# Datalynx overview

`moodle-mod_datalynx` supports flexible, database-like learning activities in Moodle. Administrators can use it to give course teams a configurable framework for collecting, displaying, and moderating structured information.

## Recommended reading path

1. Install and review site-level implications.
2. Plan the data model before creating activities.
3. Build views, filters, and templates around real use cases.
4. Define permissions, workflows, and moderation rules.

## What administrators usually own

- plugin installation and upgrades
- role capability design
- reusable templates or presets
- site-wide governance for complex use cases
