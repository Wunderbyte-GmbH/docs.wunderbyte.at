# Views, filters, and templates

Views and filters determine how users interact with Datalynx data.

## Planning checklist

- identify the main audience for each view
- decide which fields should be visible or editable
- define filters for moderation, review, or reporting
- create reusable templates where multiple courses need the same setup

## Operational tip

Treat view design as part of the workflow, not just presentation. A good view reduces support effort and keeps submissions consistent.
