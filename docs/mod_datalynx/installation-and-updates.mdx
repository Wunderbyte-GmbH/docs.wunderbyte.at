# Installation and updates

Install Datalynx like any other Moodle activity plugin and review permissions carefully before broader rollout.

## Installation path

1. Obtain the plugin package from the Moodle plugins directory or GitHub.
2. Place it in `mod/datalynx`.
3. Complete the upgrade from **Site administration > Notifications**.
4. Review capabilities and any supporting local conventions before enabling it for teachers.

## Admin review points

- confirm backup and restore expectations
- decide who may create Datalynx activities
- review capability assignments for moderation and field management
- test a sample activity before enabling broad adoption
