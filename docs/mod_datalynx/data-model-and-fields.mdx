# Data model and fields

The success of a Datalynx activity usually depends on planning the data structure before end users start creating entries.

## Questions to answer first

- What is one entry supposed to represent?
- Which fields are required?
- Which values should be standardized through selections instead of free text?
- Which fields are only for moderators or administrators?

## Administration guidance

Document reusable field patterns for your organization so course teams avoid reinventing data models that are hard to report on later.
