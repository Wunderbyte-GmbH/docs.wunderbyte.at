# Wunderbyte documentation

This site documents Wunderbyte Moodle plugins and related projects, starting with:

- `moodle-mod_booking`
- `moodle-mod_datalynx`

The first iteration is written primarily for **Moodle administrators and site owners** who need to install, configure, maintain, and roll out these plugins.

## How the documentation is organized

- **Booking** covers installation, booking setup, participant management, integrations, and administrator workflows.
- **Datalynx** covers installation, planning your data model, building views, and configuring permissions and workflows.

## Start here

- Go to [Booking documentation](/docs/mod_booking)
- Go to [Datalynx documentation](/docs/mod_datalynx)

## Current scope

This structure is intentionally compact so the documentation can expand plugin by plugin without reshaping the navigation each time.
